# DeepSeek çalışma alanı hazır

Bu klasör, DigitalBanking için ayrılmış bağımsız Git worktree'sidir. GPT'nin ana kopyası aynı üst klasördeki DigitalBanking klasörüdür. Derinlemesine görev henüz başlatılmadı; kullanıcı GPT'nin çalışmayı sürdürmesini istedi.

Devir sırasında kullan:

> DigitalBanking projesine devam et. Önce AGENTS.md, docs/LOCAL_DEVELOPMENT.md, docs/VERIFICATION.md ve docs/DEEPSEEK_HANDOFF.md dosyalarını oku. Git durumunu ve dalı doğrula. Yalnızca deepseek/dashboard-and-tests dalındaki kendi worktree'nde çalış. Devir dosyasındaki ilk dashboard sözleşmeleri ve kullanıcı deneyimi görevini uygula. Ana kopyayı değiştirme, sırları gösterme, push veya deploy yapma. Önce mevcut kontrolleri çalıştır; sonra küçük değişikliklerle ilerle. Sonuçlarını docs/DEEPSEEK_FINDINGS.md içine kaydet. Bir kontrolü çalıştırmadan başarılı deme.

Ana kopyada bu dosya yalnızca devir şablonudur. Kendi kopyanda API 5180, dashboard 5181 portlarını kullan.
